# MakerBot

> MakerBot is a desktop 3D printer manufacturer (now part of UltiMaker) and operator of Thingiverse, the largest online community for discovering, sharing, and downloading 3D-printable models. MakerBot's developer surface is the Thingiverse REST API, which exposes things, files, images, users, collections, categories, and search over a Bearer-token (OAuth 2.0) authenticated JSON API.

## APIs

- [Thingiverse REST API](https://www.thingiverse.com/developers): JSON REST API at https://api.thingiverse.com for browsing and managing Thingiverse things, files, images, users, collections, and search. Bearer-token / OAuth 2.0 authenticated.

## Docs

- [Thingiverse Developers](https://www.thingiverse.com/developers): API documentation, app registration, and authentication.
- [MakerBot](https://www.makerbot.com): Company website.
